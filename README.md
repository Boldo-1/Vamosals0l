# Portafolio fotográfico

Abre index.html para ver el portafolio. No requiere instalación ni conexión a servicios externos.

## Publicar en GitHub Pages
1. Sube el contenido de esta carpeta a un repositorio de GitHub, conservando la carpeta images.
2. En Settings > Pages, selecciona Deploy from a branch, la rama main y la carpeta / (root).
3. Guarda y espera a que GitHub muestre la dirección del sitio.

Las fotos conservan su encuadre y proporción. Miniaturas WebP de hasta 480 px y ampliaciones de hasta 2048 px. Los originales no se modificaron. Las copias no contienen metadatos EXIF.
Haz clic para abrir una foto; usa las flechas para avanzar, Escape para cerrar o desliza en un teléfono.
